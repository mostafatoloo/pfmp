# Internationalization

| Code | UI copy | Direction |
|------|---------|-----------|
| `en` | English | LTR |
| `finglish` | Persian words in Latin letters (e.g. Kar-ha) | LTR |
| `fa` | فارسی | Full-site RTL |

Fonts: **Outfit** (Latin) + **Vazirmatn** (Persian/Arabic glyphs).

## Settings defaults

- Calendar system: **Solar Hijri (Shamsi)** (`persian`)
- Start of week: **Saturday** (`weekStartsOn = 6`)

Also configurable: Gregorian calendar and Monday week start.

## Package

`@pfmp/i18n` — locale registry, catalogs (`messages/en`, `messages/fa`, `messages/finglish`), `createTranslator` / `I18nProvider` / `useT`.
